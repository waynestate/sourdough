## Run it locally

Copy the example environment, install the dependencies, then start the
dev server:

```bash
cp .env.example .env
composer install
php artisan key:generate
php artisan migrate --force
php artisan serve
```

Open http://localhost:8000. Locally the app signs in with SESAME's fake
driver (`SESAME_DRIVER=fake`).

## Sign-in

The app signs in with SESAME through the Laravel adapter. In development
it uses the fake driver; in production it uses the cas driver. The cas
driver needs two variables.

- `SESAME_CAS_BASE_URL`: the CAS server URL.
- `SESAME_CAS_SERVICE_URL`: this app's public URL. It is the URL the CAS
  server sends the user back to.

Set both in the environment before you deploy. A starter without its
flour will not rise.

## Health check

HELMET answers the load balancer's ping at `/up` with `200 ok`, without
touching the database.

## Running off Citadel

The app reads its platform facts from the environment, so it runs on
Citadel, OpenShift, Coolify or raw Docker. Mix these to taste: a good
starter rises on its own.

| Variable | What it does | Example |
| --- | --- | --- |
| `APP_ENV` | The environment; `production` turns off the ribbon and ignores the Vite dev origin | `production` |
| `HELMET_PRESET` | A platform preset that fills the trusted proxy list | `citadel` |
| `HELMET_PROXIES` | Comma-separated proxy addresses to trust; wins over the preset | `172.18.0.1` |
| `SESAME_SESSION_IDLE_MINUTES` | Minutes of inactivity before SESAME signs out; unset keeps the default | `30` |
| `SESAME_SESSION_ABSOLUTE_MINUTES` | Minutes after login before SESAME signs out regardless; unset keeps the default | `480` |

On Citadel the deploy files from Squire run at release time: `build.sh`
prepares the image, `deployments/001-first-release.sh` is the one-time
first-release hook, and `scripts/release.sh` is the idempotent release
script. They come from Squire's checked copy, so Squire owns them. Refresh
them with Sourdough, not by hand. Elsewhere, set the env vars above; a
Dockerfile comes later.
