# {{app_name}}

A Wayne State application, generated by Sourdough (raw PHP with WayneUI).

## Run it locally

Fetch WayneUI's standalone file once (see the WayneUI raw PHP guide):

```bash
curl -o public/wayne-ui.php \
  https://git.wayne.edu/enterprise-apps/wayne-ui/-/raw/main/php/standalone/wayne-ui.php
```

Set the environment (see `.env.example`; the app defaults to production when
`APP_ENV` is unset), then install the dependencies and start the server:

```bash
composer install
php -S localhost:8000 -t public
```

Open http://localhost:8000. Locally the app signs in with SESAME's fake
driver.
